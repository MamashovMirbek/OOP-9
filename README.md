# OOP-9
Abstraction in 3D Shape Modeling

This project demonstrates the concept of abstraction in Python using an abstract base class for 3D shapes. It includes the implementation of three 3D shapes (Sphere, Cylinder, Cube) and calculates their surface area and volume using random dimensions.

## Classes

- **Shape3D**: Abstract base class defining methods for surface area and volume.
- **Sphere**: Represents a sphere, calculates surface area and volume.
- **Cylinder**: Represents a cylinder, calculates surface area and volume.
- **Cube**: Represents a cube, calculates surface area and volume.

## Requirements

- Python 3.x
- math, random modules
